# 進行メモ：15分の動画と45分のハンズオン

主催者向けのメモです。
冒頭15分は[Gitのアニメーション](what-is-git-branch-150sec.html)を見ながら質問を受けます。
動画の内容を最初から講義し直す必要はありません。

## 0〜2分：今日のゴールを伝える

「自己紹介ページを3回に分けて編集・コミットし、PRを作ってCIが成功したら完了です」と伝えます。
動画にはマージや`git pull`も出てきますが、今日の必須課題はPR作成までです。
Dockerとコンフリクト解消も扱いません。

## 2〜9分：アニメーションを見る

主催者のパソコンでHTMLファイルをブラウザで開き、画面に映します。
GitHubのファイル画面ではコードが表示されるため、ファイルをダウンロードしてから開いてください。

アニメーション自体は約2分半です。
通して再生するときは「シーンの終わりで止める」のチェックを外します。
途中で質問を受けるときは、チェックを入れたままシーンごとに進めます。

前半はブランチとコミット、後半は手元とGitHubの違い、push、PR、マージ、pullの話です。
「手元でコミットしても、pushするまでGitHubには届かない」と分かれば十分です。

## 9〜13分：質問を受け、動画と課題を結び付ける

参加者が気になった場面を聞き、必要ならアニメーションを戻します。
特に「今のブランチはどこか」「コミット後の変更はどこにあるか」「PRを作ると`main`は変わるのか」を確認します。

動画のマージ場面では、`feature`と`main`が同じ場所に行を追加しています。
画面では自動で合流しますが、この例を実際のGitでマージするとコンフリクトになります。
今日は合流のイメージとして見て、コンフリクト解消は操作しません。

## 13〜15分：動画にないステージ操作を補う

動画はコミット前のステージ操作を詳しく扱いません。
ハンズオンでは1か所編集するたびに、`git diff`で内容を見て、`git add index.html`で次のコミットに入れる変更を選びます。
`git commit`で手元に記録し、3回のコミット後に`git push`でGitHubへ送ります。

ここまで確認したら[READMEの手順](../README.md#1-リポジトリを手元に用意する)へ進みます。
Gitの設定や権限で止まった人には[準備ガイド](setup.md)を案内し、エラーは省略せず画面ごと見せてもらってください。

## 15〜60分：ハンズオンの目安

| 時間 | 進めること |
| --- | --- |
| 15〜21分 | cloneとブランチ作成 |
| 21〜29分 | ページ名を編集して1回目のコミット |
| 29〜36分 | 見出しを編集して2回目のコミット |
| 36〜45分 | 自己紹介文を編集して3回目のコミット、ブラウザ確認とスクリーンショット |
| 45〜53分 | push、PR作成、画像添付 |
| 53〜60分 | CI確認と修正、予備時間 |

Gitのインストールや認証が済んでいない人は、この配分では間に合わない場合があります。
主催者は準備ガイドを案内し、先へ進める人には[追加課題](advanced-git.md)を案内してください。
